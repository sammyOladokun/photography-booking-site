# Photography Booking Starter

This workspace contains a minimal starter scaffold for a high-end photography booking site:

- `frontend/` - Next.js app (customer-facing booking form)
- `backend/` - NestJS app (bookings service)

Quick start:

```bash
# in two terminals
cd "frontend" && npm install && npm run dev
cd "backend" && npm install && npm run start:dev
```

Frontend: http://localhost:3000
Backend: http://localhost:4000
